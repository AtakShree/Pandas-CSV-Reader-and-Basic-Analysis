Overview

This project demonstrates basic data analysis using Python Pandas.

Features

- Read CSV file using Pandas
- Display dataset head, tail, and data types
- Generate summary statistics:
  - Mean
  - Median
  - Minimum
  - Maximum
  - Count
- Filter rows based on conditions
- Select specific columns
- Create subsets of data
- Export filtered data to new CSV/Excel files.

Dataset Used

Employee Dataset (CSV File).

Purpose of Project

The main purpose of this project is to learn:
- Basic Pandas operations
- CSV file handling
- Data analysis using Python
- Working with DataFrames
